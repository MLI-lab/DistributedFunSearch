Helberg-Ferreira code for s-deletion correction.
Uses Fibonacci-like recurrence: v_i = 1 + v_{i-1} + ... + v_{i-s}.
Modulus u = 1 + v_n + ... + v_{n-s+1} is FIXED by the weights.

Key limitation for systematic encoding:
- Brute-force search over all C(n,k) parity positions shows that
  NO subset of positions can span syndrome space [0, u-1].
- For n=8, s=2: u=88, weights=[1,2,4,7,12,20,33,54]
  Best with 7 bits: 84/88 coverage. Need ALL 8 bits for full coverage.
- This leaves 0 information bits - Helberg is designed for codebook
  partitioning (non-systematic), not systematic encoding.

Contrast with VT (s=1): weights [1,2,...,n] allow powers-of-2 positions
to form a binary basis spanning [0,n]. No such basis exists for Helberg.

FunSearch goal: discover weight functions where a subset CAN span [0,u-1].

def priority(n: int, s: int) -> Tuple[List[Callable], List[int], List[int]]:
    """Helberg-Ferreira code with Fibonacci-like weights. a{score}"""
    # Recurrence: v_i = 1 + v_{i-1} + ... + v_{i-s}, v_i = 0 for i <= 0
    v = [0] * (n + s + 1)
    for i in range(1, n + 1):
        v[s + i - 1] = 1 + sum(v[s + i - 1 - j] for j in range(1, s + 1))
    weights = [v[s + i - 1] for i in range(1, n + 1)]
    # Modulus: u = 1 + v_n + v_{n-1} + ... + v_{n-s+1}
    u = 1 + sum(v[s + n - 1 - j] for j in range(s))

    def weight_func(i: int) -> int:
        return weights[i]

    weight_funcs = [weight_func]
    moduli = [u]
    # Helberg requires ALL n positions as parity (verified for n=5..14, s=2)
    # n-1 positions never achieve full coverage; only ALL n works
    # This leaves 0 information bits - not useful for systematic encoding
    parity_positions = list(range(n))
    return weight_funcs, moduli, parity_positions
