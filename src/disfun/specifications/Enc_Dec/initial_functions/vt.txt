Varshamov-Tenengolts code. Single constraint with linear weights f(i) = i + 1.
Valid for s=1 (single deletion) only.

Key insight for systematic encoding: We need to choose parity positions such that
any syndrome value in [0, n] can be achieved by setting only the parity bits.
Since weights are f(i) = i + 1, positions 0, 1, 3, 7, 15, ... have weights 1, 2, 4, 8, 16, ...
These are exactly powers of 2, which form a binary basis - any integer can be written
as a sum of distinct powers of 2. This guarantees we can always find parity bit values
to encode any message (achieve any required syndrome correction).

def priority(n: int, s: int) -> Tuple[List[Callable], List[int], List[int]]:
    """VT code: f(i) = i + 1, m = n + 1, parity at 2^k - 1."""
    weight_funcs = [lambda i: i + 1]
    moduli = [n + 1]
    # Parity at positions 0, 1, 3, 7, 15, ... (2^k - 1) with weights 1, 2, 4, 8, 16, ...
    # Powers of 2 form a binary basis: any syndrome in [0,n] is a sum of distinct powers
    parity_positions = []
    k = 0
    while (1 << k) - 1 < n:  # 2^k - 1 < n
        parity_positions.append((1 << k) - 1)
        k += 1
    return weight_funcs, moduli, parity_positions
